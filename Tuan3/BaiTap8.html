Heroes of JavaScript and HTML

Heroes of JavaScript and HTML is a "Heroes of Might and Magic"-like game, but for code nerds. Each hero has its unique coding abilities and based on them he can develop software applications.

Currently the game has only four hero types:

  • Front-end Developer

    Masters of JavaScript, the order of Front-enders creates delightful user interfaces.

  • Mobile Developer

    Mobile developers craft amazing apps for devices around the world.

  • Web Developer

    Web developers are the pioneers of the Internet, mastering both old and new tools.

  • QA Engineer

    QAs ensure everything runs perfectly — no bug escapes their eyes.
